# GitHub and Vercel payload fixtures (ROADMAP T0.4)

Real payloads captured on 2026-10-30 from a throwaway private repo (`sumithprabhu/intenzo-t04-sandbox`),
with the throwaway App `intenzo-demo` installed (§12 permissions) and the repo deployed by Vercel.
They're the inputs for the T2.1–T2.4 tests (webhook intake, the run state machine, deployment matching).
Findings are in `docs/DECISIONS.md` (2026-10-30 · Platform checks).

- Webhook files are `{ event, action, deliveryId, payload }`, read back from the App's delivery log with
  `pnpm github-app:fixtures` (see `scripts/github-app/README.md`). The payload is what GitHub POSTed.
  Email values are replaced with `user@example.com` and token-shaped strings are removed; nothing else
  is changed.
- The webhook secret isn't here. Tests that need `X-Hub-Signature-256` sign the fixture with their own
  test secret.
