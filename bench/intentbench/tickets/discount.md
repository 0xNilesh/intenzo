# Discount codes

Shoppers can enter a discount code on the cart page.

- A "Discount code" field with an "Apply" button sits under the cart items.
- SAVE10 takes 10% off the subtotal and shows as its own line in the order summary: "Discount (SAVE10)" with the amount, −$5.00 for the $50.00 cart.
- The total updates right away, without a page refresh: $50.00 becomes $45.00.
- The expired code OLD5 shows the message "This code has expired", and nothing else changes.
- The savings chart in the summary shows the discount as its own slice.
